📋 QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════

  STEP 1: Install Dependencies
  ────────────────────────────
  Double-click: install.bat
  
  This will install all required packages:
  • OpenAI (for AI brain)
  • pyttsx3 (for voice output)  
  • sounddevice (for voice input)
  • And more...

  STEP 2: Launch Siya
  ────────────────────
  Double-click: run_siya.bat
  
  A beautiful window will open with an animated cat!

  STEP 3: Start Chatting!
  ────────────────────────
  • Click "🎤 Speak" to talk
  • Or click "⌨️ Type" to type
  • Watch the cat animate!
  • Hear Siya respond with voice!

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════

  Problem: Dependencies won't install
  Solution: Make sure you have Python 3.8+ and internet

  Problem: No voice output
  Solution: Check speaker volume and Windows TTS settings

  Problem: Microphone not working  
  Solution: Allow microphone access in Windows Privacy settings

  Problem: API errors
  Solution: Verify .env file has correct OpenAI API key

  For more help, read QUICKSTART.md
