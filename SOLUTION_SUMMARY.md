## 🚀 Quick Start (Choose One)

### 🏠 Option 1: Ollama (Recommended!)

**Why:** Completely free, private, unlimited

**Steps:**
```bash
1. Visit https://ollama.com
2. Download and install
3. Run: ollama run llama2
4. Run: python siya_free.py
```

**Time:** 10 minutes (includes 4GB download)

---

### ☁️ Option 2: Groq API

**Why:** Quick setup, no downloads

**Steps:**
```bash
1. Visit https://console.groq.com
2. Sign up (no credit card!)
3. Get API key
4. Edit siya_free.py:
   - Set GROQ_API_KEY = "your_key"
   - Set USE_LOCAL_AI = False
5. Run: python siya_free.py
```

**Time:** 5 minutes

## 🐛 Troubleshooting

### Problem: "Couldn't connect to my brain"
**Solution (Ollama):**
```bash
ollama serve
ollama run llama2
```

### Problem: "API error" 
**Solution (Groq):**
1. Check API key is correct
2. Verify `USE_LOCAL_AI = False`
3. Check internet connection

### Problem: Emoji shows as boxes
**Solution:**
- Update to Windows 10/11
- Or ignore, everything still works!
